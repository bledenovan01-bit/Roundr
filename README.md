# Roundr

Application mobile Expo / React Native pour organiser des matchs et tournois de football amateur.

- `frontend/` : l'application (Expo SDK 58).
- `docs/` : rapports de recette et de préparation.
- `memory/`, `plan/` : cahier des charges et plan du projet.

Depuis `frontend/` : `npx --yes yarn@1.22.22 install --frozen-lockfile`, puis `npm test`.
